# Louxos — Portfolio

Portfolio personnel de Louis, alias Louxos, créé en HTML, CSS et JavaScript sans outil de compilation. Les images des projets sont des aperçus issus des projets de Louxos : Noto et Glue Flip, ainsi qu’un aperçu du site LouxosCorporation.

## Aperçu local

Depuis la racine du dépôt :

```sh
python3 -m http.server 8000
```

Puis ouvrir <http://localhost:8000/>.

## Publication GitHub Pages

Le dépôt est configuré pour publier la racine de la branche `main` sur <https://louxos.github.io/>. Une fois les modifications fusionnées dans `main`, GitHub Pages les publie automatiquement. `index.html` est la page d'accueil ; `style.css`, `script.js` et le dossier `assets/` contiennent ses ressources.

Le portfolio utilise le lien de contact du site LouxosCorporation et ne contient pas de configuration Firebase.
