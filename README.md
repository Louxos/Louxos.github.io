# Louxos — Portfolio

Portfolio personnel de Louis, alias Louxos, créé en HTML, CSS et JavaScript sans outil de compilation.

## Aperçu local

Depuis la racine du dépôt :

```sh
python3 -m http.server 8000
```

Puis ouvrir <http://localhost:8000/>.

## Publication GitHub Pages

Le dépôt est configuré pour publier la racine de la branche `main` sur <https://louxos.github.io/>. Une fois les modifications fusionnées dans `main`, GitHub Pages les publie automatiquement. Le fichier `index.html` est la page d'accueil ; `style.css`, `script.js` et le dossier `assets/` sont nécessaires à son affichage. Le fichier `index modele.html` est conservé comme référence et n'est pas la page d'accueil.
